# React-admin-dashboard
🛒 eCommerce Management System
A Full-Stack eCommerce Application built with the MERN stack (MongoDB, Express.js, React.js, Node.js). This project offers a complete shopping experience, including user authentication, product management, cart functionality, and an admin dashboard.

🚀 Features
User Features
🌟 User Authentication: Register, login, and manage profiles securely.
🛍️ Product Browsing: View detailed product listings with search and filtering options.
🛒 Shopping Cart: Add products to your cart, adjust quantities, and proceed to checkout.
💳 Payment Gateway: Simulate a payment process for seamless transactions.
Admin Features
📦 Product Management: Add, update, and delete products.
📈 Dashboard: Monitor sales, manage orders, and track inventory.
👥 User Management: View and manage registered users.
🛠️ Tech Stack
Frontend
React.js: Dynamic and responsive user interfaces
Redux: State management
Chakra UI / Ant Design: Modern and accessible UI components
Backend
Node.js: Server-side JavaScript runtime
Express.js: Lightweight framework for API development
Database
MongoDB: NoSQL database for scalable data storage
Others
JWT: Secure user authentication
Axios: API calls for frontend-backend communication
Git: Version control for collaborative development
